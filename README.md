# Gun Holsters (Forge 1.20.1)
Requiere: Forge 47.x, Curios API 5.x, Vic's Point Blank (+ Civilian Gun Pack opcional).

Compilar: instala JDK 17 y ejecuta `gradle build` (o sube la carpeta a GitHub: la Action genera el .jar en "Artifacts").
El .jar queda en build/libs/.

- Slots nuevos: Funda de cintura (armas cortas) y Funda de espalda (armas largas).
- Teclas (configurables en Controles > Gun Holsters): G = cintura, H = espalda.
- Config: gunholsters-common.toml (palabras clave de armas cortas, duracion) y gunholsters-client.toml (posicion/rotacion).
